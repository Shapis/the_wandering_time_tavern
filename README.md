# The Wandering Time Tavern

A living repository for stories, campaigns, characters, worlds, and everything created along the way.

This repository is shared between its creators and serves as the home for both **finished stories** and **ongoing campaigns**. Each project can develop its own setting, characters, lore, and history while still belonging to the larger collection.

## Stories & Campaigns

Each story or campaign gets its own directory. Projects should be self-contained whenever possible, with their worldbuilding, narrative material, and session notes kept together.

### Current Projects

- **Humble Beginnings** — The first story/campaign in the repository.

## Project Structure

A typical campaign may contain folders such as:

```text
Project Name/
├── Characters/
├── Factions/
├── Items/
├── Locations/
├── Maps/
├── Quests/
├── Secrets/
├── Sessions/
└── The Story/
```

Not every project needs every folder. The structure should serve the story rather than restrict it.

## Organization

- **Characters** — protagonists, player characters, recurring characters, and important individuals.
- **Factions** — organizations, groups, families, kingdoms, cults, guilds, and other powers.
- **Items** — significant objects, artifacts, equipment, documents, and other notable possessions.
- **Locations** — towns, buildings, regions, landmarks, and other places.
- **Maps** — regional maps, local maps, diagrams, and other visual references.
- **Quests** — ongoing, completed, planned, or discovered objectives.
- **Secrets** — information that should remain hidden from players or characters until revealed.
- **Sessions** — session notes, events, decisions, consequences, and continuity records.
- **The Story** — the main narrative, plot, chapters, and overarching direction of the project.

## Collaboration

This is a shared workspace. Changes should help preserve continuity and make the project understandable to both creators.

When adding new material:

1. Keep related information close to where it belongs.
2. Avoid creating duplicate versions of the same character, place, or event.
3. Treat established story details as canon unless they are explicitly marked otherwise.
4. Use clear names and consistent terminology.
5. Keep experimental ideas separate from established material when possible.

## Canon & Changes

The repository is expected to evolve. Stories may change, ideas may be discarded, and established details may be rewritten as the campaign develops.

When something changes in a meaningful way, update the relevant files rather than leaving conflicting versions scattered throughout the project.

## The First Chapter

**Humble Beginnings** is the first project to live here. It establishes the beginning of the repository and provides the foundation for everything that follows.

More stories and campaigns can be added alongside it as the collection grows.
